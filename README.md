# ToDo管理アプリ

日々のタスクを登録し、期限・カテゴリ・優先度・完了状況を管理できるWebアプリケーションです。
インストールやサーバーの起動は不要で、ブラウザだけで動きます。

---

## 1. 起動方法

1. ZIPファイルを展開します。
2. `todo-app` フォルダの中の **`index.html`** を、ブラウザ（Google Chrome を推奨）で開きます。
   - ダブルクリックするか、ブラウザのウィンドウにドラッグ＆ドロップしてください。
3. 画面が表示されたら、そのまま使えます。

> ※ インターネット接続・インストール・サーバーの起動は必要ありません。
> ※ 登録したタスクは、使っているブラウザの中（LocalStorage）に保存されます。ページを再読み込みしたり、ブラウザを閉じたりしても消えません。
> ※ 別のブラウザや、ブラウザのシークレットモードでは、保存したデータは共有されません。

### スマートフォンで確認する場合

動作確認用に、同じ内容のアプリをインターネット上に公開しています。スマートフォンのブラウザで次のURLを開くと、そのまま使えます。

**https://seimeikawasaki-alt.github.io/todo-app/**

- 内容は提出したZIPファイルと同じです。
- 登録したタスクは、開いた端末のブラウザの中に保存されます。ほかの人に見られることはありません。
- ZIPから開いた場合とこのURLで開いた場合では、データは別々に保存されます。
- 公開が不要な場合は停止いたしますので、お知らせください。

## 3. 実装した機能

### 必須機能（要件定義書 第3〜6章）

| 機能 | 内容 |
|---|---|
| タスク登録 | タスク名・詳細・期限・カテゴリ（仕事／プライベート／その他）・優先度（高／中／低）を登録 |
| 入力チェック | タスク名が空（空白だけの場合も含む）のときは登録せず、「タスク名を入力してください」と表示 |
| 一覧表示 | タスク名・期限・カテゴリ・優先度・完了／未完了の状態を表示 |
| 完了／未完了の切り替え | 「✓ 完了にする」「↺ 未完了に戻す」ボタンで切り替え（スマホは「›」で開く詳細から）。各行の左端の丸とその下の文字で今の状態（未完了／完了）を表示。完了したタスクは緑のチェック・取り消し線・薄い表示で区別。切り替えた直後のお知らせの「元に戻す」で取り消せる |
| 編集 | 編集画面で全項目を変更でき、一覧にすぐ反映 |
| 削除 | 削除前に「このタスクを削除しますか？」と確認 |
| 絞り込み | ステータス（すべて／未完了／完了）とカテゴリ（すべて／仕事／プライベート／その他）。組み合わせも可能 |
| 並び替え | 期限順（期限が近い順）・優先度順（高→中→低）・登録順 |
| データ保存 | LocalStorage に保存。再読み込みやブラウザを閉じた後も残る |
| スマートフォン対応 | 幅375pxでも崩れないレイアウト。スマホでは登録・詳細・絞り込みを下から出てくる画面で操作 |

### 追加機能

| 機能 | 内容 |
|---|---|
| 期限入力用カレンダー | 曜日・祝日が分かるカレンダー。**年と月をプルダウンで選べる**ので、数年先の期限もすぐに設定できる |
| 時刻の設定 | 期限に時刻（時・分）を設定できる（任意） |
| 期限ごとの見出し | 期限順のとき「期限切れ／今日／明日／今週／それ以降／期限なし」に分けて表示 |
| サマリーカード | 未完了・今日・期限切れ・完了の件数。押すとその条件で絞り込む |
| 残り時間の表示 | 「あと40分」「あと3日」「2日超過」など。期限切れは赤、今日が期限はオレンジで表示 |
| キーワード検索 | タスク名と詳細から検索。絞り込みと組み合わせられる |
| 完了済みのまとめ表示 | 「すべて」のとき完了済みを一覧の下にまとめる（開閉でき、状態を保存） |
| 詳細パネル | タスクを押すと詳細を表示（PCは右側、画面が狭いときはモーダル、スマホは下から表示） |
| 週表示 | 縦軸に時間、横軸に7日間の表。「前の週／前の日／今日／次の日／次の週」で移動でき、週の始まり（今日／月曜／日曜）も選べる。現在時刻の線、各日の件数、土日・祝日の色分け。空いたマスを押すとその日時で登録できる |
| 祝日の表示 | 日本の祝日を計算で求めて表示（振替休日・国民の休日にも対応） |
| プロジェクト | 仕事のタスクをプロジェクトにまとめられる。作成・編集（8色）・アーカイブ・削除 |
| 集計 | 完了率、期限切れ、プロジェクトごとの進み具合、期限内に完了できた割合、直近8週間の完了数、未完了の内訳、改善のヒント |

## 4. 仕様について（独自に判断した点）

- **期限のないタスク**は、期限順では一番最後に表示します。
- **時刻のないタスク**（終日）は、その日の終わりまでを期限として扱います。同じ日の中では、時刻のあるタスクの後に並びます。
- **並び替えで同じ順位になった場合**は、期限順なら優先度→登録が新しい順、優先度順なら期限→登録が新しい順で並べます。
- **ステータスが「すべて」のとき**、完了済みのタスクは一覧の下の「完了済み」にまとめて表示します（その中も、選んだ並び順で並びます）。ステータスで「完了」を選ぶと、区切らずに表示します。
- **サマリーカードの「今日」**は、今日が期限で、まだ期限を過ぎていない未完了のタスクの数です。期限を過ぎたものは「期限切れ」に数えます。
- **「今週」の見出し**は、明後日から「今週の終わり」までのタスクです。週の終わりは、週表示の「週の始まり」の設定に合わせます（初期設定は「今日から7日間」）。
- **プロジェクト**は、カテゴリが「仕事」のタスクだけに設定できます。カテゴリを仕事以外に変えると、プロジェクトの設定は外れます。
- **プロジェクトを削除**しても、タスクは削除せず「プロジェクト未設定」に戻します。
- **完了の切り替え**は、何度も行う操作なので確認画面は出しません。代わりに、切り替えた直後のお知らせに「元に戻す」ボタンを表示し、押し間違えてもすぐに取り消せるようにしています（完了日時も元の値に戻ります）。削除は取り消せないため、要件どおり確認画面を出します。
- **Enter キーでは登録しません。** タスク名を入力して Enter を押しても登録されず、「追加」「保存」ボタンを押したときだけ登録します（押し間違いで登録されるのを防ぐため）。
- **各行の左端の丸は、状態を示す表示だけ**です。押しても切り替わりません（押し間違いを防ぐため）。切り替えは文字付きのボタンで行います。
- **週表示の「前の日」「次の日」**は、PCでは表示している7日間を1日ずつずらし、スマホでは選んでいる日を1日ずつ移動します。「今日」を押すか、週の始まりを変えると、通常の区切りに戻ります。
- 入力した文字は、画面にそのまま文字として表示します（HTMLのタグとして扱わないので、`<script>` などを入力しても安全です）。
- 保存データが壊れていた場合は、新しい状態で開き、壊れたデータは別の名前で残します。

## 5. ファイル構成

```
todo-app/
├── index.html            画面の枠組み
├── README.md             このファイル
├── css/
│   └── style.css         デザイン（色などはCSS変数で管理）
├── js/
│   ├── date-utils.js     日付の計算（日本時間で日付がずれないよう、年・月・日に分けて扱う）
│   ├── holidays.js       日本の祝日の計算
│   ├── storage.js        LocalStorage への保存と読み込み
│   ├── tasks.js          タスク・プロジェクトの追加・更新・削除、絞り込み・並び替え・集計
│   ├── ui.js             画面部品の共通処理（モーダル・確認画面・お知らせ）
│   ├── datepicker.js     期限入力用カレンダー
│   ├── task-form.js      タスクの入力欄
│   ├── task-dialogs.js   登録・編集・削除確認・詳細の画面
│   ├── list-view.js      リスト表示（ホーム画面）
│   ├── week-view.js      週表示
│   ├── dashboard-view.js 集計画面
│   ├── projects-view.js  プロジェクト管理画面
│   └── app.js            起動と画面の切り替え
└── tests/
    └── logic.test.js     自動テスト（任意）
```

## 7. 補足

### データを消したいとき
ブラウザの設定から、このページのサイトデータ（LocalStorage）を削除してください。保存キーは `todo-app-data` です。

### 祝日について
祝日は祝日法に基づいて計算しています。法律の改正などで特別に決まった祝日は、`js/holidays.js` の `EXCEPTIONS` に追加してください。

### 自動テストの実行（任意）
Node.js がインストールされている場合は、`todo-app` フォルダで次のコマンドを実行すると、日付・祝日・絞り込み・並び替え・保存の処理を確認できます。

```
node tests/logic.test.js
```
